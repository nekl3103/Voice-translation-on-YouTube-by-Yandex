# Video Voice Translate

Расширение для Google Chrome, которое переводит доступные субтитры видео и озвучивает перевод во время просмотра. Работает на YouTube; другие сайты можно добавить в настройках.

> **Как работает перевод:** расширение читает субтитры плеера, переводит их через встроенный [Translator API Chrome](https://developer.chrome.com/docs/ai/translator-api) и озвучивает системным голосом. Оно не распознаёт речь непосредственно из аудиодорожки и не использует сервисы Яндекса.

## Возможности

| Функция | Что доступно |
| --- | --- |
| Языки | Английский → русский по умолчанию; выбор исходного и целевого языка; автоопределение исходного языка |
| Озвучка | «Обычный» и «Живой» режимы системного синтеза речи |
| Субтитры | Переводные субтитры поверх видео можно включить или скрыть |
| Звук | Регулировка громкости оригинала; после выключения перевода прежняя громкость восстанавливается |
| Окно | Видео можно открыть в Picture in Picture |
| Сайты | YouTube подключён сразу; дополнительные домены подключаются с отдельным разрешением |
| Инкогнито | Поддерживается после разрешения в настройках Chrome |

## Установка

### Из релиза

1. Скачайте архив [последнего релиза](https://github.com/nekl3103/Voice-translation-on-YouTube-by-Yandex/releases/latest) и распакуйте его.
2. Откройте `chrome://extensions` и включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите распакованную папку, в которой лежит `manifest.json`.
4. Откройте видео на YouTube и нажмите **Озвучить** в панели над плеером.

Для установки из исходников вместо архива выберите папку этого репозитория. Требуется настольный Chrome 138 или новее с доступными [Translator API](https://developer.chrome.com/docs/ai/translator-api) и [Language Detector API](https://developer.chrome.com/docs/ai/language-detection). При первом переводе Chrome может загрузить языковой пакет.

### Обновление

Замените файлы в папке установленного расширения файлами новой версии, нажмите **Обновить** на карточке расширения в `chrome://extensions` и перезагрузите открытые страницы с видео.

## Использование

1. Подведите указатель к видео: компактная панель появится по центру его верхнего края и скроется после паузы в движении мыши.
2. Откройте меню **⋯**, чтобы выбрать исходный и целевой языки. Исходный язык можно переключить на **Авто**. Если определение ошиблось, выберите язык вручную.
3. Нажмите **Озвучить**. Подсветка кнопки означает, что озвучивание включено. Расширение включит субтитры плеера, если они были выключены, и начнёт переводить появляющиеся реплики.
4. В меню **⋯** также можно выбрать голос, включить или скрыть переводные субтитры, настроить громкость оригинала и автоматический перевод новых видео.
5. Нажмите подсвеченную кнопку **Озвучить** ещё раз, чтобы остановить озвучку и вернуть исходную громкость и состояние субтитров.

Маленькая кнопка отдельного окна на панели использует Picture in Picture. Панель управления и переводные субтитры остаются на исходной вкладке.

### Другие сайты

Откройте карточку расширения в `chrome://extensions`, нажмите **Параметры расширения** — настройки откроются прямо на странице Chrome. На вкладке **Доступ к сайтам** введите домен и подтвердите запрос Chrome на доступ к нему. Затем обновите вкладку с видео. Доступ можно отключить на той же вкладке. Список учитывает активные разрешения Chrome. Chrome может оставлять удалённый сайт в карточке расширения как ранее разрешённый: `permissions.remove()` снимает активный доступ, но не стирает историю согласия. При повторном добавлении этого сайта Chrome может не показать запрос снова. Если сайт использует встроенный плеер с другого домена, добавьте и домен плеера.

На дополнительных сайтах расширение читает доступные HTML5-субтитры (`TextTrack`) и субтитры некоторых распространённых плееров. Поддержка зависит от устройства конкретного сайта.

### Инкогнито

Chrome не разрешает расширениям включать доступ к инкогнито автоматически. Откройте карточку расширения в `chrome://extensions` и включите **Разрешить использование в режиме инкогнито**. После этого обновите приватную вкладку с видео.

## Ограничения

- Без доступных субтитров перевод не работает. Распознавания речи из аудио пока нет; прямые трансляции без субтитров также не поддерживаются.
- Количество говорящих людей и смена голосов в аудиодорожке не определяются: расширение работает с субтитрами и озвучивает перевод одним голосом.
- «Живой» режим ищет более естественный голос среди доступных голосов Chrome и системы. Он не копирует голос автора видео; при отсутствии такого голоса используется обычный.
- Синтезированная речь может отставать от видео. Результат зависит от длины реплик, скорости перевода и доступных голосов.
- Shorts, закрытые плееры и сайты, не предоставляющие субтитры странице, могут не работать.
- Настройки хранятся в `chrome.storage.sync`. Текст субтитров не отправляется на сервер расширения; Chrome может загружать языковые пакеты, а некоторые системные голоса могут использовать сеть.

## Если перевод не включается

| Симптом | Что проверить |
| --- | --- |
| Кнопка не появилась | Обновите вкладку после установки расширения. На другом сайте сначала добавьте его домен в настройках. |
| Озвучивание включено, но речи нет | Проверьте, есть ли у видео субтитры и включается ли их кнопка в плеере. |
| Не скачивается языковой пакет | Проверьте интернет и доступность Translator API в установленном Chrome; попробуйте выбрать язык исходной речи вручную. |
| Нет озвучки | Проверьте звук системы и наличие голоса для целевого языка. |

## Разработка

Расширение использует Manifest V3 без сборщика и внешних библиотек. Основные файлы: `manifest.json`, `background.js`, `content.js`, `content.css` и страница настроек `options.html` / `options.js` / `options.css`.

Версия в `manifest.json` соответствует тегу релиза. Для локальной проверки синтаксиса:

```sh
node --check content.js
node --check background.js
node --check options.js
python3 -m json.tool manifest.json >/dev/null
```
